## ❓ 常见问题（FAQ）

**Q：安装时提示「未知来源」怎么办？**
A：进入系统设置 → 安全/应用 → 开启「允许安装未知来源应用」，或直接在弹窗中选择「仍要安装」。

**Q：安装后打开闪退？**
A：请确认设备 Android 版本满足要求，并重新下载最新版本安装。
